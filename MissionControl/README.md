# BUS311 Mission Control

BUS311 Mission Control is the instructor-facing macOS app for Fall 2026 lesson access. It reads the maintained `terms/fall-2026.json` release states; lesson cards always remain on the student homepage, while locked lessons render as noninteractive upcoming previews.

Use `swift run` from this directory during development. Saving runs the maintained homepage builder and public site validator. Saving never commits, pushes, or publishes the change.
